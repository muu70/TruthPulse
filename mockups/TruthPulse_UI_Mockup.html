HONESTY INDEX · SAMPLING
  • 数値はすべて等幅数字（monospacedDigit）。1桁変動でレイアウトが揺れない
  • 行間は一律1.35倍。暗所・薄暗い居酒屋での可読性を優先
  • Dynamic Type は xSmall〜AX3 に対応。AX以上ではメトリクスが3列→1列に自動再配置

シェイプ・余白・触覚

  • 角丸はすべて Continuous Curved（.rect(cornerRadius:style:.continuous)）。カード22px / ボタン20px / タッチパッド26px
  • 画面左右パディング 20pt、カード内 16–18pt、要素間 8pt グリッド
  • スコア脈動：1.1秒周期の二段ビート（1.045→1.0→1.02）で心拍を模倣
  • 触覚：計測中 .impact(weight:.light) を心拍と同期、結果表示で .success / .warning
  • 指置きエリアは 96×96pt以上のヒットエリアを確保

アクセシビリティ

  • 判定は色だけに依存しない。アイコン＋テキストラベル＋バー長の3重符号化
  • Reduce Motion ON時：脈動・走査ラインを停止し、クロスフェードに置換
  • Reduce Transparency ON時：ガラスを不透明サーフェス #141830 に自動フォールバック
  • VoiceOver：スコアリングに accessibilityValue「誠実度72パーセント」を付与。ライブ更新は .accessibilityRespondsToUserInteraction で抑制
  • 全タップターゲット 44×44pt以上／フォーカスリングは Cyan 2pt
  • 免責表示を全結果画面に常設し、誤解を防止
